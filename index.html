How this map is made

  • Warming is the change in near-surface air temperature vs the 1850-1900 average of the same grid cell.
  • Averaging in time: monthly values are averaged to years, then smoothed with a 10 year centered average so one hot year cannot count as a crossing. The last few years use shorter averaging windows.
  • Crossing year: each cell is colored by the first year that smoothed warming reaches the threshold. Purple means it was already there in 2000, the first year shown. Gray means it never gets there by 2100.
  • One model, one run: all data comes from a single climate model (GFDL-ESM4) under three emissions scenarios, so each map is one possible path, not a forecast.
